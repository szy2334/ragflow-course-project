- 普通用户不能提交 RAGFlow `dataset_id`、`document_id` 或检索词；只能提交 `format_profile_id` 和规则 ID。
- Profile 公共接口不会泄露私有数据集 ID；管理接口支持同一 `profile_key` 的新版本。
- 任务提交时冻结 Profile、规则及 RAGFlow 映射，结果可复现。
- 缺少可测量版式特征时，审查输出必须是 `needs_manual_check`，不能猜测。

## 部署注意事项

当前桌面 Windows 开发环境中，Psycopg 异步检查点驱动不支持默认 Proactor 事件循环，因此开发模式安全使用无 LangGraph 检查点运行；核心任务与答案数据仍进入 PostgreSQL。生产部署请使用 Linux，或明确配置 Windows Selector 事件循环后再启用 PostgreSQL LangGraph 检查点。

## 本次前端状态修订

- 移除了过时的“图表 OCR”“可问答”“论文完成理解后将显示摘要”等界面文案；新标签分别是“内容补全”“可阅读”，且摘要缺失时展示当前真实的入库或模型可用性状态。
- `PAPER_INGEST_FAILED` 不再被界面重复渲染为无行动信息的泛化失败文案；页面会标明失败阶段、错误编号，并提示从该阶段重试及保留错误编号用于诊断。
- `understanding.status = unavailable` 被视为已成功结构化入库的合法结果。详情页不会再访问不存在的 `facts` 字段，阅读和原文检索入口仍可使用。
- 论文列表对非终态论文每 4 秒刷新一次，直到进入 `ready` 或 `failed`，避免用户停留在旧进度。
